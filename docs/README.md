# YOLOv11-ConvNeXt

A YOLOv11 object detection model with ConvNeXt backbone.

## Features

- YOLOv11 detection head with ConvNeXt backbone
- Multiple model sizes (Tiny, Small, Base)
- Efficient training and inference pipeline
- Easy deployment with multiple export formats

## Installation

See [docs/INSTALLATION.md](docs/INSTALLATION.md) for detailed installation instructions.

```bash
pip install -r requirements.txt
```
